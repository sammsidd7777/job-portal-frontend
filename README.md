# ✨ Project Overview

The MERN Job Portal is a complete recruitment platform that connects job seekers with recruiters through a modern and intuitive interface.

Candidates can search and apply for jobs, upload resumes, and manage their profiles, while recruiters can post jobs, manage applicants, and maintain company information.

The project is designed with scalability, security, and performance in mind.
